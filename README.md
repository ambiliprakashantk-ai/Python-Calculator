Python Calculator

Project Description

A simple command-line calculator developed using Python. It performs basic arithmetic operations.

Features

- Addition
- Subtraction
- Multiplication
- Division
- User-friendly menu
- Exception handling
- Division-by-zero error handling

Technologies Used

- Python
- Visual Studio Code

Concepts Used

- Functions
- Conditional Statements
- Loops
- Exception Handling
- User Input

How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project in VS Code.
4. Run the following command:

python calculator.py
